# Smart Expense Tracker 💰

A simple and responsive expense tracker built with **HTML, CSS, and JavaScript**.

## 📌 About

Smart Expense Tracker allows users to add, manage, and track their daily expenses. It provides a simple way to understand where your money is going.

## ✨ Features

* ➕ Add new expenses
* 🗑️ Delete expenses
* 💰 Calculate total expenses
* 📅 Track expenses by date
* 📊 View spending summary
* 📱 Responsive design
* 💾 Store data in the browser

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage


### 2. Open the project

```bash

```

### 3. Run the project

Open `index.html` in your web browser.
